## Notes

GreenOvercast is an unofficial Xbox Cloud Gaming and GeForce NOW client for
Linux handhelds. You need internet access and an account for your chosen
service. Xbox requires a Game Pass plan that includes cloud gaming; GeForce
NOW requires a membership and access to the games you want to play.

Choose a service, then open the sign-in link shown on screen on another device
and enter the code. Your login is saved. You can switch services from Settings.

Tested on the RG35XX-H with muOS, the RG40XX-H with Knulli and ROCKNIX
20260801, the Miyoo Flip with SpruceOS, and the R36S with AmberELEC.
GeForce NOW has been tested on muOS, Knulli, SpruceOS, and dArkOS on the R36S.
R36S frame pacing still needs work; ROCKNIX and AmberELEC testing covers Xbox.
The release requires glibc 2.38 or newer. ArkOS is not supported.

## Controls

| Button             | Library / menus                   | In game                           |
| ------------------ | --------------------------------- | --------------------------------- |
| D-Pad / Left Stick | Navigate; hold to scroll faster   | Movement                          |
| A                  | Select, play, or type              | Xbox A                            |
| B                  | Back or cancel                    | Xbox B                            |
| X                  | Search or delete a letter         | Xbox X                            |
| Y                  | Favorite a game or clear search   | Xbox Y                            |
| L1 / R1            | Switch All / Favorites            | Xbox LB / RB                      |
| L2 / R2            | Jump by first letter              | Xbox LT / RT                      |
| Start              | Settings or apply search          | Xbox Menu                         |
| Select             | —                                 | Xbox View                         |
| L3 + R3            | —                                 | Xbox Guide                        |
| Select + Start     | Exit after holding for one second | Exit after holding for one second |

Settings include Xbox/Nintendo face-button layouts, game artwork, and Sign
out. Games that return a 16:9 stream remain letterboxed on 4:3 displays.

GeForce NOW uses the same gamepad controls. For store dialogs and game
launchers, press Select + Y to toggle mouse mode: D-pad or left stick moves the
pointer, A clicks, B right-clicks, and L1 / R1 scroll. Store sign-in may still be
required inside the stream.
